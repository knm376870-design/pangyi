# 旁译 v4.16.0｜648 条表情映射，中英切换更顺，候选窗更稳

这次更新，让旁译在学习和聊天时更好用：表情与颜文字更丰富，英文模式切换更可靠，切走应用后候选窗自动收起，鼠标划过设置面板也更稳定。

**[下载 Windows 安装包：pangyi-v4.16.0.exe](https://github.com/knm376870-design/pangyi/releases/download/v4.16.0/pangyi-v4.16.0.exe)**

## 新增与改进

- **表情与颜文字从 170 扩充至 648 条映射**，覆盖 435 个不同关键词，包含常用、网络流行表达及颜文字。同一个关键词可能对应多个候选；648 不是独立表情数量。
- **英文、表情模式开关支持热重载**：设置面板修改后，运行中的应用通常约 0.5 秒内生效，并显示状态提示。这项改进仅覆盖英文、表情两个开关。
- **单按 Shift 快速切换中/英**，配合状态提示，当前模式更清楚。
- **长颜文字显示更完整**：候选窗会按内容调整宽度，减少截断。

| 输入完整关键词 | 表情候选示例 |
| --- | --- |
| `zqsg` | 🥹 |
| `dbq` | 🥺 |
| `xdm` | 🤝 |
| `jrm` | 🥰 |
| `yyds` | 👑、🐮 |

表情仅在开启表情模式、完整匹配关键词时加入候选列表，并排在前面；不会写入自学习词库。这里的表情是 Unicode 字符与颜文字，并非图片表情包，外观可能随系统字体变化。

## 修复内容

- **英文开关真正生效**：修复设置面板开启英文模式后，输入法未正确读取设置的问题。
- **Caps Lock 大写更可靠**：改进部分应用未将 Caps Lock 按键交给输入法时的大写状态识别。
- **候选窗自动收起**：修复打字中切换应用、关闭浏览器或聊天窗口后，候选栏仍残留在屏幕上的问题。焦点变化与前台窗口检测共同处理残留窗口。
- **设置面板悬停闪屏修复**：改进设置面板与候选窗绘制，鼠标划过选项时只更新必要区域。

本版本包含此前未单独发布的 v4.14.1、v4.15.0 相关改进。

## 怎么使用

1. 下载并运行本页安装包。首次安装后，按安装提示注销并重新登录，或重启电脑。
2. 按 `Win + 空格` 切换到「旁译」，敲拼音即可查看中文候选与已有的俄语释义。
3. 双击桌面「旁译」打开设置，开启「表情模式」。保持中文模式，完整输入 `xdm`，选中 🤝 后按空格确认；关闭表情模式后，表情候选停止注入。
4. 需要英文时，单独轻按一下 `Shift` 切换中/英；也可在设置面板调整英文模式。Caps Lock 用于大写输入。

## 需要重启吗？

| 场景 | 需要做什么 |
| --- | --- |
| 首次安装 | 按安装提示注销并重新登录，或重启电脑，完成系统输入法加载 |
| 从旧版升级 | 保存工作，完全退出并重开使用旁译的应用（包括后台进程），让应用加载新版组件；若仍未更新，注销后重新登录 |
| 日常开启/关闭英文模式、表情模式 | 无需重开应用或重启电脑，通常约 0.5 秒内生效 |

热重载生效的前提是应用已加载 v4.16.0，不能用修改开关代替升级后的组件重载。
